データについて

この画面は記録されたデータをそのまま表示します。進捗率・完成率などの推計は行いません。

データ形式: schema_version が 1 の JSON オブジェクト。各配列は200件、各文字列は2000文字までを検証します。

取得方法: HTTP経由では state.json を15秒ごとに自動取得します（5秒でタイムアウト、1MiB上限）。file:// では自動取得できないため、JSONファイルを選択して読み込んでください。

リンク許可範囲: ../docs/ 配下の安全な子パス、または同階層の index.html・state.json のみ。許可外のパスは文字列として表示します。
