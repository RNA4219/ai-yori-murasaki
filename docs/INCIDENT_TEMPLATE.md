# Incident 記録の雛形

`IN-YYYYMMDD-xxx.md` として複製する。未発生の障害を実績として登録しない。

## 検知と影響

検知日時・方法、影響した原文・判断・成果物、検知時の版を記録する。

## 原因と復旧

再現条件、根拠、根本原因、実施した復旧、検証結果を記載する。
原因が分からない場合は未確定とする。

## 再発防止

必要な [EVALUATION](../EVALUATION.md) / [RUNBOOK](../RUNBOOK.md) の変更と、後続 Task / Acceptance を結ぶ。

## タイムライン

日時はタイムゾーン付きで記載し、日本時間の記録は UTC+09:00 とする。
