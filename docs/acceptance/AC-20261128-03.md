# 資料の取り込みと出力の検収条件

## Scope

[Task 20261128-03](../tasks/TASK.followup-security-review-11-28-2026.md) の合成資料を使って、次の結果を確認する。

## Acceptance Criteria

- CLI から対応形式のレポート、ローカルの参照資料、読み取り専用 MCP の資料を取り込める。取り込みはファイルや受信データの制限を適用し、接続用の値を資料に残さない。
- 案件を登録する際に認可記録を保護する。案件の表示、履歴、図と出典には、閲覧時点の秘密設定を適用する。Blue では操作者向けの情報を公開しない。
- 判断画面とその JSON 出力に同じ表示条件を適用する。通常の出典を開ける。書き出し先を検査し、不適切な指定で既存データが変わらない。
- 評価の出典・版・日時を保存済みの資料に照合する。スコアの出典を確認できない場合は、過去の評価を再表示する場合も未確認として扱う。
- 受付検索では、表示できる案件名に基づいて並び順・件数・次ページの有無を決める。過去の案件、実行と評価を表示するときは、検証した台帳の記録をそのまま使う。
- 認証・キャッシュを含む独立した読み直しと、最終コミットを指定した manual-bb の strict 判定を実施する。実サービスの設定や実アカウントでの運用確認は今回の範囲外とする。
