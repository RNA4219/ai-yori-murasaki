# 判断の画面と記録モニターの技術検収

## Scope

[改修要件](../tasks/TASK.frontend-review-11-22-2026.md)に基づく、読み取り専用の2画面とその間の移動。画面には製品サーバーから配信したHTMLと、試験用に用意した案件・公開記録を使った。

## Acceptance Criteria

- [x] 判断すべき件数と未完了件数が先頭に出る。未評価・未検査の表示を保ち、詳細で理由を確認できる。
- [x] 案件の目的名、状態、検知件数、最終実行日時を390pxの画面内に表示する。
- [x] 案件を保って画面を往復できる。案件の記録を読み直して非公開となったとき、以前の課題は表示されない。
- [x] 「すべての課題」から全件を表示できる。モニターを更新しても、開いた接続状態の詳細は開いたままになる。
- [x] キーボードから本文をスキップしても対象案件を保つ。動きを減らす設定で詳細を開ける。ローカルファイルで同梱JSONを選択して読める。
