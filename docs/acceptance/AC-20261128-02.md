# 資料とモニターの公開範囲の検収条件

## Scope

[Task 20261128-02](../tasks/TASK.offline-security-boundaries-11-28-2026.md) の取り込み、資料の読み取り、モニターの案件表示と索引をローカルで確認する。

## Acceptance Criteria

- 既存の案件索引を `aym monitor index` で更新できる。Blue の案件一覧・明細・件数に、旧形式を含む操作者用の課題が出ない。
- 保存済みの資料を CLI とモニターから開くと、保護対象の文字列が題名・本文に表示されず、該当する出典や関連リンクは開けない。通常の出典は読める。課題の読み取りにも現在の秘密設定が反映される。
- 対象の入力ファイルと保存オブジェクトを読み取るとき、通常ファイルと指定サイズを確認し、読み込み中に対象が変われば結果を採用しない。
- モニターは同時接続枠とタイムアウトを適用し、処理終了後は枠を戻す。Windows では使用中のモニターポートを排他的に確保する。
