# モニターの Google ログインの技術検収

## Scope

[R-089](../requirements/GOOGLE-MONITOR-SSO.md) の CLI、モニター4画面、データ API・配信ファイルへのアクセスを、ループバックと合成アカウントで検証する。[Task 20261127-04](../tasks/TASK.google-monitor-sso-11-27-2026.md)

## Acceptance Criteria

| T61 の操作・条件 | 期待する結果 |
| --- | --- |
| 通常起動と、SSO 指定で必須設定が欠けた起動を比較する | 通常は Google の設定なしで使える。SSO 指定で設定が足りない場合は起動を中止する。 |
| セッションがない状態で4画面、データ API、配信ファイルを開く | 各画面はログインへ案内し、API や配信ファイルから保護対象の内容を取得できない。 |
| 許可した合成アカウントで Blue 画面に戻る | 元のビューと既存の表示制限を維持する。 |
| キャンセル、許可外のアカウント、認証要求と対応しない応答を確認する | ログインを完了せず、画面からやり直せる。 |
| ログアウト、セッション期限切れ、サーバー再起動後に同じページを開く | 再認証を求め、古いセッションでデータを取得できない。 |
| PC と幅375 pxのブラウザーで認証前後を操作する | ログイン・再試行・ログアウトの操作と結果を読み取れる。 |

## Evidence

CLI と HTTP の入口は [API 契約](../requirements/API-CONTRACTS.md#21-基本) に記載した。関連試験は合成した署名済みトークンを使う[認証の試験](../../tests/test_google_sso.py)、ループバックの[モニターの試験](../../tests/test_monitor_auth.py)、[Chromium で4画面を操作する試験](../../tests/browser/google-sso.browser.mjs)。製品コミットに対するローカル試験と正式 manual-bb の結果は検証後に記録する。
