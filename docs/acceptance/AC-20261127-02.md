# 構成図切替の技術検収

## Scope

[Task 20261127-02](../tasks/TASK.architecture-switch-11-27-2026.md) のうち、ワークスペースの構成図を読み取る API とモニターの画面を検収する。使用する図は合成データとする。

## Acceptance Criteria

| T58 の確認項目 | 期待する結果 |
| --- | --- |
| 一覧・個別取得 | 有効な図がファイル名順で最大100枚並び、ID で図を取得できる。不明な ID は 404、読めない図は 409。 |
| 切替と復帰 | モニターから構成図を選び、再読込後も選択を保持する。製品図・見本へ戻ると表示と URL が切り替わる。 |
| 未保存の編集 | 切替確認をキャンセルすると編集内容、選択、URL が維持される。 |
| 不明 ID と空一覧 | 不明な ID では理由と見本が表示される。空の作業場所では選択欄が現れず、見本を操作できる。 |
| Blue | 図の有無によらず、両 API が `{"status":"withheld"}` を返す。Blue のモニターから構成図へ進んでもワークスペースの図を表示しない。 |
| 幅375 px | 横にスクロールせずに選択欄を操作でき、図とアドレスが切り替わる。 |
| 読み取り専用 | 選択、編集、再読込を経ても、ワークスペースに置いた図の名前と内容が変わらない。 |
