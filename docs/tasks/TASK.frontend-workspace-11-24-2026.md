# 案件の選択から根拠の確認まで

モニターで案件を選び、重要度別の検知を開き、判断画面で対応を決める。構成図では部品や線を選び、根拠を隣で読む。受付台帳では名前か受付IDで記録を探す。4つの入口をどの画面からも同じ順で利用でき、判断画面とモニターの往復では案件を引き継ぐ。

構成図の関与範囲と人型、正規入力の線、ドラッグ、ホイール操作、一列のツールバーを維持する。選択の紫と重要度の黒・赤・黄・緑を区別し、色には名前と件数を併記する。スマートフォンとデスクトップの確認は[技術検収](../acceptance/AC-20261124-01.md)に記録した。

Blueの表示モードは上部タブと画面内の補助リンクで引き継ぐ。モニターには案件一覧の取得に成功した時刻を表示する。未保存の構成図を別の図に置き換えるときは、元の図を維持したままキャンセルとJSONの書き出しを選べるようにする。

通常のJSON書き出しでも、ブラウザーに保存を依頼した時点では編集保護を維持する。利用者が保存を確認したときに解除し、その後の編集で再び保護する。
