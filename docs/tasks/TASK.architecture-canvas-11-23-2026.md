# 構成と接続の図を直接操作する

部品をドラッグまたはキーボードで移動しても、背景の区画とその見出しを表示する。

利用者の関与範囲に含める部品を明示的に指定し、図の上で枠を描く。ドラッグによる複数選択と個別の追加・解除に対応する。範囲は部品IDで保存し、配置や画面幅が変わった場合も選択した部品を囲む。

利用者入力がある送信元カードの上に、人型のコマと「利用者」のラベルを置く。コマからカードへ矢印を向け、利用者・操作画面・送信先の順を示す。

有向の接続記録ごとに、画面からの利用者入力、内部処理、未指定を区別する。利用者入力には、画面から指定できる項目や値の範囲を記述できる。矢印または部品の接続一覧から設定を編集し、構成図JSONとして保存・再読込できる。

指摘のある構成要素には、記録された重大度ごとの名称と件数を表示する。Criticalは黒、Highは赤、Mediumは黄、Lowは緑とし、選択した部品の指摘詳細にも同じ色を使う。情報レベルの記録は灰色で区別する。

表示範囲の切り替え、倍率、全体表示、配置を戻す操作を1行に並べる。製品の図の見出しは「ai-yori-murasaki の構成図」とする。図の下の操作説明と検証報告、集計部品に付けた実装説明を取り除く。

図の上では修飾キーなしのホイールでポインター位置を中心に上下どちらにも倍率を変えられる。図の外ではホイールでページをスクロールできる。

「構成と接続」で箱を自由に配置し、拡大・縮小とパンで関係を追う。接続線を選ぶと、方向、接続理由、根拠を読める。配置はそのタブで開いている図ごとに扱う。同じ線に複数の記録がある場合はすべて表示する。[技術検収](../acceptance/AC-20261123-09.md)
