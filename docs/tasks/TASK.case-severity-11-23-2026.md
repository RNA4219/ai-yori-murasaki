# 案件の重要度別件数から検知を開く

選択した案件について、元の検知に記録された重要度ごとの件数を表示する。件数を押すと、その案件・重要度に属する明細を確認できる。同じ検知IDは一件とし、評価の状態や対応完了の有無によって件数を変えない。

一覧の抜粋は4件までのため、集計には索引内の全検知を使う。旧索引からの移行、一部未集計・未集計・確認済み0件、重要度の欠損、ブラウザー操作は[技術検収](../acceptance/AC-20261123-08.md)で確認する。
