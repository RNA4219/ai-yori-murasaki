# 資料インポート・出典リンク・明るい画面

## Objective

ユーザーが承認した読み取り専用インポートを追加する。ObsidianのMarkdown、NotionとGitHub IssueのMCP読取結果を、出典リンク付きの調査資料として保存する。画面を白基調にし、本文・表・操作要素の文字を大きくする。

## Scope

手動CLIインポート、MCP接続設定、出典・追加リンク、再取り込みの重複／更新判定、operator専用の資料一覧・本文表示を対象とする。取り込み先の書き換え、自動同期、任意MCPツール実行、資料のOracle正解やRSI学習への自動転用は含めない。既存の未追跡スクリプト4本は保持する。

## Contract

資料はFindingとは別に保存し、常に未検証の参考資料とする。URL、取得時刻、本文hash、履歴を保持する。同一出典・同一内容は再登録せず、更新は過去のCASを保持して新しい版にする。外部本文はHTMLとして解釈しない。Blue向けHTTPには資料の内容・件数・存在を公開しない。

MCPは公式Python SDKの明示的な読取クライアントを使う。接続設定は操作者が指定し、資格情報は環境変数名で参照する。読取ツールの許可リスト、時間・出力上限を設け、設定や認証値を資料へ保存しない。実接続は認証と対象が用意された場合だけ確認する。

白い背景、濃い本文、紫のアクセントを使う。本文18px、補助文・表・ボタン16px以上、見出しはそれより大きくする。既存の自動更新・フォーカス・画面幅への対応を維持する。従来のチャコール指定は今回の明示指示で置き換える。

## Acceptance Criteria

- 指定したObsidianノートと、許可したMCP読取結果を取り込める。
- 出典と追加リンクを一覧・詳細から開ける。不正なURLやHTMLを実行しない。
- 再送の冪等性、更新履歴、欠落・破損・権限境界を試験する。
- 実ブラウザーで白基調・文字サイズ・390px幅・キーボード・リンク操作を確認する。
- 実接続、ローカルMCP試験、fixture、未実行を区別して記録する。

## Evaluation Identity

機能・状態機械・UIの回帰試験であり、性能比較・実候補の昇格は実施しない。GLM／DeepSeekの利用枠制限に対するこのセッションでのCodex代行承認を引き継ぐ。

## Result

承認範囲の実装・検証を完了した。全体657 passed / 3 skipped / 22 subtests passed、最終HTML関連24 passed。実SDKのローカルMCP、CLI、保存と境界、実ブラウザーの両幅を確認した。実利用者の外部サービス接続とOAuthログイン画面は含めない。詳細は[AC-20261109-02](../acceptance/AC-20261109-02.md)、[証跡](../evidence/sources-light-ui-20261109/README.md)、[使い方](../SOURCES.md)。CHANGELOGは0018。ソース反映は追加指示による[RA-20261109-02](../releases/RA-20261109-02.md)に基づき、該当PRの結果で追跡する。
