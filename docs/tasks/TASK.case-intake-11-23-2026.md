# 案件受付と登録索引

初期監査とは独立して案件名を受け付ける。Rustで受付IDと再送キーの索引を更新し、同一キーの同時送信を1件にまとめる。モニターから受付IDまたは案件名で検索できる。

受付済みの10万案件に1件を登録し、同内容の再送後も100,001件であることを確認する。受付操作で監査実行が作成されないことも照合する。[技術検収](../acceptance/AC-20261123-05.md)
