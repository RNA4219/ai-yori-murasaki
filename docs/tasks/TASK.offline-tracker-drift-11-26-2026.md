# 課題一覧と観測の照合

案件の担当者が、課題の状態を見直す根拠を判断画面からたどれるようにする。入力は Notion の課題 CSV と、取得方法・範囲・日時を持つ資源一覧または検知一覧。照合は案件単位で行い、状態更新は担当者が判断する。

## 受入条件

- 毎回同じ CSV を取り込んでも同じ案件で課題が増えない。入力を拒否した場合、一部だけが課題一覧に載ることを防ぐ。
- CSV の課題を観測に結び、未解決の課題と消えた資源・検知、完了済みの課題と残る検知を識別する。照合できない課題は理由別に集計する。
- 課題に対応する資源 ID や名前、検知、取得日時を表示する。判断画面で候補を選んで根拠を開ける。
- CSV・Markdown・JSON に結果を書き出せる。照合と表示は原本や課題記録を書き換えず、Blue ビューは照合の内訳を非公開にする。
