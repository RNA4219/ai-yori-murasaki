# モニターの Google ログイン画面を整える

ログインと再試行の画面では、製品名、現在の状態、次の操作を中央のカードにまとめる。明るい配色ではカードの上辺を青にし、濃紺の「Google でログイン」ボタンをカードの幅いっぱいに置く。スマートフォンでも案内を最後まで読めて、キーボードやタッチ操作でログインを開始できるようにする。
