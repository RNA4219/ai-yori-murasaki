# ADR-0002: RSI の方針と評価契約

## 背景

ユーザーから、自己改善を整理した9項目を、本プロジェクトへ追加する依頼を受けた。

## 判断と理由

[RSI 方針](../RSI.md) を正本として、目的と条件の固定、旧版との同条件比較、未見課題、任意の経験メモリ、採用判断と反映の分離を設計・運用へ接続する。
実行中の仮説更新と、run 間での candidate の変更を区別する。参照資料固有の採点器・反復回数・閾値はそのまま採用しない。

## 影響

今後の RSI Task は [契約](../CONTRACTS.md#rsi) と [RUNBOOK](../../RUNBOOK.md#rsi) に従う。
今回の変更は文書への組み込みであり、自己改変コード、永続メモリ、採用評価器、実行器への自動反映は実装しない。実装完了と性能向上の実証を別々に検収する。
