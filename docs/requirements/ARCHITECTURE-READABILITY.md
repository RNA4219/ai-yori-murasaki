# 大きな構成図を読み、要素の種類を追加する

## R-087　図の等倍表示と要素の絞り込み

PC・スマートフォンともに、モニターの「システム構成図」で図を上、選んだ要素や接続の詳細を下に表示する。大きな図は等倍で開き、「全体を表示」で配置を見渡した後に等倍へ戻せる。

1. モニターの「システム構成図」を開き、図をドラッグして見たい場所へ移る。拡大・縮小は倍率のボタン、ホイール、ピンチで操作できる。
2. 要素を探すには、名前、ID、種類、種別（`type`）の一部を検索欄に入力する。検索対象は現在の表示モードに含まれる要素で、種類は ID と表示名のいずれでも探せる。検索条件を消すと、そのモードの一覧に戻る。
3. 図上の要素を選ぶか、検索結果から要素を選んで移動する。図の下で詳細を読み、確認を終えたら「図に戻る」を押す。選んだ要素または接続にフォーカスが戻り、続けて図を操作できる。

## R-088　利用者が定めた種類の登録と割り当て

各要素の `kind` には種類を識別する文字列を指定できる。標準の `repository`（リポジトリ）、`service`（サービス）、`store`（データストア）、`external`（外部システム）は従来の JSON のまま使える。独自の種類に名前を付けるには、図の最上位に任意の `nodeKinds` 配列を追加する。指定した `id` が要素の `kind` と一致すると、その `label` を種類名として表示する。未登録の種類は ID で読める。各要素の `type` には引き続き製品名などの補足を書ける。

```json
{
  "schema": "aym.architecture/v1",
  "name": "配送受付の見本",
  "nodeKinds": [{"id": "queue-worker", "label": "配送処理"}],
  "nodes": [
    {"id": "desk", "name": "受付", "kind": "service"},
    {"id": "worker", "name": "伝票作成", "kind": "queue-worker", "type": "夜間バッチ"}
  ],
  "connections": [{"from": "desk", "to": "worker", "label": "伝票を依頼"}]
}
```

上の JSON を UTF-8 で保存し、「構成ファイルを開く」で選ぶ。「配送処理」で検索すると「伝票作成」を見つけられる。詳細では種類だけを変更することも、新しい種類の ID と表示名を入力して選択中の要素へ割り当てることもできる。「構成図を保存」で書き出し、そのファイルを開き直すと、追加した種類の表示名と割り当てが復元される。[ワークスペースに図を置く手順](ARCHITECTURE-MAP-SELECTION.md)

独自の種類は1図につき100件まで。要素の `kind`、種類の `id` と `label` は前後の空白を除き、残った値を Unicode コードポイントで1〜160文字とする。たとえば ` 🚚 ` は `🚚` として保存し、1文字と数える。ID は標準の4種と登録済みの種類を含めて一意にする。

## T59・T60　表示とファイルの検収

T59 はモニターから合成図を開き、PC と幅375 pxで倍率・検索・詳細への移動・図への復帰を確認する。T60 は種類を追加し、要素への割り当てから JSON の保存・再読込までを確認する。標準4種だけの従来形式と、表示名を定義していない独自の種類も対象とする。[検収条件](../acceptance/AC-20261127-03.md)
